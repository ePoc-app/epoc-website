L'export SCORM génère un package `.zip` que vous pouvez importer dans un LMS compatible SCORM (Moodle, etc) pour proposer votre ePoc à vos apprenants.

## Exporter

::steps{level=5}
##### Cliquer sur la flèche à droite du bouton **Publier** en haut à droite
##### Choisir **Export SCORM**
##### Choisir un emplacement et un nom pour le fichier `.zip`
::

Le package contient `index.html` et `imsmanifest.xml` à la racine de l'archive, ainsi que le lecteur ePoc et le contenu de votre ePoc dans `assets/`. Le manifeste est généré automatiquement à partir de l'identifiant et du titre de votre ePoc.

## Importer dans un LMS

Ajoutez une activité de type **SCORM** dans votre cours et déposez le fichier `.zip` exporté, sans le décompresser. Le fonctionnement exact dépend de votre LMS, référez-vous à sa documentation.

::alert{icon="lucide:info"}
Le package utilise la version 1.2 de SCORM. Lorsque le LMS le permet, la progression et le score de l'apprenant lui sont remontés.
::

## Quel export choisir ?

| Besoin | Export |
| --- | --- |
| Partager l'ePoc dans l'application mobile | [Publier](/guide/user/export-and-publish) (`.epoc`) |
| Mettre l'ePoc en ligne dans un navigateur | [Export HTML](/guide/user/export-and-publish/html) |
| Intégrer l'ePoc dans un LMS | Export SCORM |
